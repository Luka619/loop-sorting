# UI 视觉优化清单

用于跟踪 UI 视觉改进，完成后用 [x] 勾选。

## 优先级：高
- [x] 增强道路与背景的区分（降低道路亮度/饱和度，为可交互元素加轻微投影或外发光）。
- [x] 强化弹窗聚焦（加深遮罩、弱化厚重内阴影）。
- [ ] 规范主次 CTA（主按钮橙色尺寸/高度/圆角/阴影统一，次级绿/灰对齐）。
- [ ] 提升弹窗文字可读性（手动断行，字号 +1~2，行距略增）。
- [ ] 顶部 HUD 对齐（基线一致，左右安全边距一致）。

## 优先级：中
- [ ] 提升关卡标签对比度（描边/柔和阴影）。
- [ ] 优化开始页间距（标题与 CTA 更大呼吸感）。
- [ ] 结算页间距（标题与奖励按钮间距增大；按钮宽度统一）。

## 优先级：低/可选
- [ ] 检查所有弹窗圆角和边框厚度一致。
- [ ] 检查图标风格一致（齿轮、播放、关闭）。
