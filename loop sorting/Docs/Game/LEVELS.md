# Loop Sorting 关卡规划

> 总索引：`../README.md`

本文件只放“关卡设计规范/节奏规划/关卡说明”。玩法与系统细节请看 `DESIGN.md`。

## 制作规范（必须执行）
- 传送带可以闭合或不闭合，取决于关卡设计；但必须保持“单条传送带”的清晰形态。
- 传送带形式只允许：
  - 单条闭合成一圈（可勾选 `loop`），或
  - 单条不闭合的单向路径（不勾选 `loop`）。
- 传送带容量：`beltCapacity` 必须按关卡目的与难度设计（低容量=高压力、高容量=高容错），避免长期固定为同一个数值。
- 禁止两条传送带重合/贴合造成视觉与逻辑混乱。
- 空间利用率：尽量减少大面积空白；闭合一圈时优先把箱体放进圈内，提高画面利用率；箱体不要与传送带叠在一起。
- 箱体开口：必须开在“短边”并且朝向传送带最近侧。
  - 左/右开口：通常 `rows < columns`（例如 10×3）。
  - 上/下开口：通常 `columns < rows`（例如 3×10）。
- 颜色总量规则（当前关卡体系）：默认箱体容量为 30（3×10 或 10×3）。每种参与的颜色总量必须能完整填满某个箱体（推荐每色 = 30），否则可能出现无法达成胜利条件。
- 成行规则（避免“不成行”）：每个箱体内，任一颜色在该箱体的数量应为“单行积木数”的整数倍。
  - 上/下开口：单行积木数 = `columns`（例如 3×10 的单行是 3；该箱体内某色用 10 会变成 3 行多 1 个，禁止）。
  - 左/右开口：单行积木数 = `rows`（例如 10×3 的单行是 3）。
- 每关视觉要“看起来很不一样”：箱体数量、位置、开口方向、传送带形状要有变化，避免清一色矩形闭环。

## 设计理念
- 视效与逻辑一致：开口方向、绑定槽位、入箱条件在编辑器预览与运行时必须一致。
- 节奏：前期用 3×10/10×3 保持操作反馈频繁；后期通过更多箱体、更多颜色、容量压力、隐藏/锁箱逐步叠加复杂度。

## 30 关节奏规划（隐藏色从 10 关开始；锁箱从 20 关开始）
1-3：新手教学（出货/进货/开口/绑定槽位/分流）
4-9：基础强化（更多箱体/更多颜色/路径变化/容量压力，但无隐藏无锁箱）
10-19：引入隐藏色并组合（隐藏 run 的认知与规划；仍无锁箱）
20-30：引入锁箱并组合（解锁顺序、锁箱与隐藏/容量压力/道具的组合）

## 31-40 关节奏规划（大师段：综合与变化）
目标：在玩家已掌握“隐藏色 + 锁箱”后，用“解锁链 + run 分段 + 缓冲位（空箱）管理 + 路径变化”提供不同体验，避免纯堆数量。

### 31-40 关一览（实现已落地到 `Assets/Levels/31.asset` ~ `Assets/Levels/40.asset`）
- 31：复习锁箱（Red 解锁）+ run 分段入门（外层 6 的短 run），难度 3/5（belt=48）。
- 32：Red 解锁强化（更多锁箱）+ run 分段强化（外层 6 的短 run），难度 4/5（belt=45）。
- 33：非闭合路径 + 解锁链（Red → Blue），强调“先解锁再补齐颜色总量”，难度 4/5（belt=42）。
- 34：呼吸关（无锁箱）+ 更直观的信息（仅最深段 hidden），难度 3/5（belt=55）。
- 35：小峰值（Red 解锁 3 箱 + Blue 解锁 1 个空箱缓冲位），强调容量压力与节奏控制，难度 5/5（belt=40）。
- 36：换解锁色（Orange 解锁）+ 组合复习，难度 4/5（belt=44）。
- 37：非闭合路径 + Orange 解锁，强调“先完成指定色再展开局面”，难度 4/5（belt=41）。
- 38：小峰值（Purple 解锁多箱体），强调信息不完全与顺序，难度 5/5（belt=38）。
- 39：呼吸关（无锁箱）+ 变体配色分布，难度 3/5（belt=58）。
- 40：终局（Orange 解锁主内容 + Red 解锁缓冲位），强调长线规划与失误救回，难度 5/5（belt=36）。

### 统一约束（31-40 必须满足）
- 仍遵循本文件“制作规范（必须执行）”，尤其是“单条传送带”“开口在短边”“颜色总量可填满箱体”“成行规则”。
- 本段关卡统一使用 3×10 / 10×3（容量 30）以保持视觉一致与手感清晰；颜色段计数尽量使用 3 的倍数（避免不成行）。
- 传送带容量（`beltCapacity`）按关卡做差异化，用于控制“缓冲空间 vs 压力”，避免 31-40 每关都同一种节奏。

## 第 3 关规格（当前实现参考）
- 建议箱体：以 3×10（或 10×3）为主，开口在短边且朝向传送带。
- 传送带：闭合一圈，槽位 50，整体围住箱体区域以提高空间利用率。

## 关卡设计流程（建议执行顺序）
### 1) 先定“目的”（这关教什么/考什么/让玩家爽什么）
每关必须能用一句话说清楚其设计目的，常见类型：
- 教学关：让玩家学会 1 个新概念/新规则（例如：空箱延后入箱、隐藏色、锁箱）。
- 练习关：重复练习同一目标，但换布局/换干扰项，形成肌肉记忆。
- 变体关：在不引入新机制的前提下，通过路径/开口/箱体分布制造新局面。
- 组合关：把已出现的机制做“组合题”，考规划与应对失误。
- 呼吸关：在一段高强度后给 1 关明显更轻的体验（也可以承担视觉换肤/奖励展示）。

### 2) 选“机制集合”（本关允许出现的机制/约束）
按章节节奏先圈定本关能用的机制，再做布局与数值：
- 1-9：只用基础机制（无隐藏、无锁箱），重点在开口/绑定槽位/分流与容量压力。
- 10-19：加入隐藏色（组合但不叠加锁箱）。
- 20-30：加入锁箱（与隐藏/容量压力/道具做组合）。

### 3) 设“难度目标”（这关在曲线上的位置）
不要用“凭感觉”，给每关一个明确的难度定位与目标：
- 曲线位置：入门 / 熟练 / 进阶 / 高压 / 峰值（可用 1-5 星或 S/A/B/C）。
- 目标体验：更偏“爽快出货”还是“长线规划”，更偏“容错高”还是“步步为营”。
- 预期时长：首次通关时长/失败率目标（例如：首次 45-75s、失败率 < 20%）。

### 4) 用“难度杠杆”实现难度（从易到难逐层叠加）
优先用“空间与信息”制造难度，再用“限制”制造压力：
- 决策复杂度：箱体数量↑、颜色数↑、同色分布更碎、关键色更稀缺。
- 规划深度：传送带更长/槽位更紧张、关键入箱点更靠后、需要等一圈的情况更多。
- 压力调节：传送带容量（`beltCapacity`）↓ 会显著提高“必须及时入箱/避免误送”的压力；容量↑ 则更偏规划与容错。
- 容错与压力：更接近满槽失败、关键箱体更靠近边缘（更容易误点/误送）、引入锁箱/隐藏导致信息不完全。
- 干扰与错觉：开口方向混合、箱体距离传送带更近但入口更刁钻（仍需保持“单条传送带”清晰）。
引入新机制时建议“降其他杠杆”：先让玩家学懂，再把压力加回来（例如先减少颜色/箱体数）。

### 5) 做“视觉草图”（先构图再填数）
先在竖屏构图里摆出传送带与箱体的位置关系，再开始填颜色段，避免最后为了数值牺牲可读性。

### 6) 填内容与校验（保证可解、可读、可达成）
落地时做 3 个强制校验：
- 规则一致性：开口方向/绑定槽位/入箱条件在编辑器预览与运行时一致（见 `DESIGN.md`）。
- 颜色总量：每种参与颜色的总量必须能完整填满某个箱体（推荐每色 = 30）。
- 失败压力：确保存在“可能接近满槽但可通过策略缓解”的过程，避免纯随机/纯死局。

### 7) 试玩迭代（固定顺序）
每关至少跑一轮：设计者自测 → 未参与设计者冷启动测试 → 记录失败点与误解点 → 回到步骤 1-4 调整。

## 单关规格模板（推荐写到表格或关卡备注）
- 关卡目的：一句话（教学/练习/变体/组合/呼吸）。
- 使用机制：基础 / 隐藏色 / 锁箱 / 道具（如有）。
- 传送带参数：`beltCapacity`（容错/压力），`loop`（闭合/不闭合），构图模板（O/U/S/折线）。
- 箱体规格：优先 3×10 / 10×3（容量 30），并遵守“成行规则”。
- 难度定位：在全流程的位置（例如：第 12 关 = 隐藏色练习 2/3，难度 3/5）。
- 难度杠杆：本关主要靠哪些杠杆变难（最多 2 个主杠杆 + 1 个辅杠杆）。
- 关键体验点：玩家必须“意识到”的 1 个点（例如：空箱延后入箱会改变最优解）。
- 视觉主题：构图模板（O/U/S/折线）、开口方向组合、箱体分布要点。
- 通过标准：预期时长/失败率/是否允许 1 次明显失误仍能救回。

## 难度分布建议（让玩家体验最佳的节奏）
### 1) “教-练-拧”循环
每引入一个新要点，建议用 3 关完成一个小循环：
1) 教学：单一目标、低压力（少颜色/少箱体/更宽松槽位）。
2) 练习：同目标重复但换布局（防止记忆解）。
3) 拧一下：加入 1 个已学过的干扰项（例如容量压力/开口方向混合）。

### 2) “渐进爬坡 + 周期回落”
推荐在 30 关内保持：
- 主体趋势缓慢上升（避免连续陡增）。
- 每 3-5 关出现 1 次小峰值，然后给 1 关回落作为呼吸。
- 峰值关尽量由“组合题”承担，而不是单纯堆数量。

### 3) 难度校准的两个红线
- 不要让“信息不完全”（隐藏/锁箱）与“满槽高压”在同一关首次同时出现。
- 不要用“更难 = 更多颜色/更多箱体”作为唯一手段；优先让布局与入箱窗口制造差异。

## 新机制出现频率（出现后如何安排）
### 1) 机制引入后的“近距重复”
机制首次出现后，建议在接下来的 5-6 关里至少出现 3 次（以免玩家遗忘），并按“简单→常规→组合”递进。

### 2) 机制稳定期的“间隔复现”
当玩家已经掌握后：
- 让该机制保持 1/3 ~ 1/4 的出现率（例如每 3-4 关至少 1 关出现），保证熟练度不断档。
- 若连续 2 关都用了该机制，第 3 关尽量换成其它体验（避免疲劳）。

### 3) 新机制对难度的影响（如何抵消/放大）
- 引入期：新机制天然增加认知负担，建议降低其它压力（颜色↓/箱体↓/槽位更宽松）。
- 熟练期：可以逐步把压力加回去，用新机制去“改变解题方式”，而不是只让它当作额外限制。
- 组合期：同一关最多 2 个“强机制”叠加（例如隐藏 + 锁箱），并清晰地让玩家知道这一关的主考点是哪一个。

## 竖屏视觉布局规划（以可读性与空间利用率为第一优先）
### 1) 安全区与信息层级
- 顶部预留 HUD/提示区域，核心操作区放在中下部；避免把关键入箱口顶到屏幕边缘。
- 保持“单条传送带”的视觉主线清晰：宁可简单也不要复杂到读不出方向与入口。

### 2) 常用构图模板（建议做成关卡“视觉库”循环使用）
- O 型闭环：传送带围住箱体（优先把箱体放进圈内，提高空间利用率）。
- U 型半包围：开口朝内，玩家更容易理解“入口窗口”。
- S 型/折线：用于中后期的路径变化关，但要避免贴边与重叠导致混乱。

### 3) 箱体摆放原则（竖屏更友好）
- 优先用“上窄下宽/上少下多”的重心（下方留给更多箱体与手指操作空间）。
- 开口朝向传送带最近侧，且开口一定在短边（已在本文件上方规范中要求）。
- 视觉差异优先来自：箱体数量/开口方向组合/传送带形状/箱体分布，而不是仅换颜色。
