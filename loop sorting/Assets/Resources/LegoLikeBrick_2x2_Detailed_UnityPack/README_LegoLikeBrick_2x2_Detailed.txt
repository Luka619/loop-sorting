LegoLikeBrick_2x2_Detailed
- PivotBottom: Y=0 is the bottom of the brick.
- PivotCenter: centered to overall bounds (incl. studs).

Unity import tips:
1) Keep OBJ and MTL in the same folder.
2) If faces look missing, set the Model Importer -> Normals = Calculate and Recalculate Tangents.
3) Materials in URP/HDRP: create a Lit material and assign it manually.
