# Loop Sorting 关卡规划

## 制作规范（执行必遵）
- Loop 仅在路径首尾重合时勾选；非闭合不要强行 loop。
- 传送带只有两种：单条闭合一圈，或单条非闭合单向；禁止重叠双轨/复杂回环。
- 空间利用率：传送带边界尽量贴近箱体排布，减少左右/上下空白；能放进圈内的箱体尽量放在圈内，不与带重叠。
- 开口与尺寸：开口必须在短边且朝向传送带最近侧；开口左右时 rows < columns，开口上下时 columns < rows（常用 3×10 或 10×3）。
- 布局习惯：优先用 3×10（或 10×3）保持可操作节奏，特殊需求再调整。

## 设计理念
- 视觉与逻辑一致：首尾不重合不勾选 loop；闭合后再开启 loop，避免尾部“瞬移”。
- 3×10 习惯：行高 10、列宽 3，外层可操作量稳定，操作节奏细密，便于预判容量。
- 核心目标：循序引入搬运顺序、暂存分流、开口方向、隐藏/锁定、容量管理、道具使用；每 5 关强化或新增机制。

## 30 关节奏规划（隐藏从 10 关起，锁箱从 20 关起）
1. 新手 1：单 loop，2 框（3×10），单色拆分，教出货/进货。  
2. 新手 2：单 loop，3 框（3×10），双色交叉，教“先外层，再内层”。  
3. 新手 3：单 loop，3 框（3×10），无隐藏无锁，巩固基础。  
4. 节奏 4：单 loop，3 框，双色不均衡配比，练分流。  
5. 节奏 5：单 loop，4 框，三色，强调“绕一圈再回填”。  
6. 节奏 6：单 loop，4 框，双开口方向（上下），练开口理解。  
7. 节奏 7：单 loop，4 框，带容量降低，练节奏控制。  
8. 节奏 8：单 loop，5 框，小批量多色，强调颜色阻塞。  
9. 节奏 9：单 loop，5 框，双色错位，必须拆散再合。  
10. 进阶 10：单 loop，5 框，引入“隐藏色”概念（无锁箱）。  
11. 进阶 11：单 loop，5 框，隐藏分布增多，仍无锁箱。  
12. 进阶 12：单 loop，6 框，多开口方向，强调“最近槽位”。  
13. 进阶 13：非 loop，6 框，尾不回收，教差异。  
14. 进阶 14：非 loop，6 框，带容量偏小，要求精准分批。  
15. 进阶 15：单 loop，6 框，三色均衡但布局错位，练逆向分配。  
16. 进阶 16：单 loop，6 框，隐藏与分流结合，仍无锁箱。  
17. 进阶 17：单 loop，7 框，多开口（左右/上下），强调对齐。  
18. 进阶 18：单 loop，7 框，隐藏色集中在单箱，数量提升。  
19. 进阶 19：单 loop，7 框，带容量中等，三色占比 4:3:3，练均分。  
20. 高阶 20：非 loop，7 框，首次引入锁箱（解锁色显性），无隐藏。  
21. 高阶 21：单 loop，8 框，锁箱 + 路径转折（平滑槽位）。  
22. 高阶 22：单 loop，8 框，锁箱与隐藏组合，解锁后显现隐藏。  
23. 高阶 23：单 loop，8 框，带容量降低，颜色块更大（≥5 连续行）。  
24. 高阶 24：非 loop，8 框，色配不均，奖励使用完成色道具。  
25. 高阶 25：单 loop，8 框，三色 + 伪陷阱色（极少量），需暂存避免污染。  
26. 高阶 26：单 loop，9 框，锁箱依赖中距离箱体，强调时机。  
27. 高阶 27：单 loop，9 框，隐藏分布在两箱，外层不同色。  
28. 高阶 28：非 loop，9 框，带容量极低，考节奏与暂存（可用乱序道具）。  
29. 高阶 29：单 loop，9 框，三色均衡 + 锁箱 + 隐藏，要求严谨排序。  
30. 终局 30：单 loop，10 框，复合：双锁箱 + 多隐藏 + 长路径，多道具可用。

## 第 3 关规格（当前已实现）
- 布局：主要箱体使用 3×10（columns=3, rows=10，blockSize≈0.3 → size≈0.9×3），开口放在短边。
- 传送带：闭合矩形，首尾重合并开启 loop，槽位容量 50，路径：  
  (-2,6) → (8,6) → (8,-8) → (-2,-8) → (-2,6)（单圈围住箱体，压缩左右/上下空白，提高利用率）。
- 箱体：  
  - Box A（上，开口向下，3×10）：红 18（外层），蓝 6（次层），蓝 6 隐藏（最内层），位置 (0, 3.5)，位于圈内上方。  
  - Box B（下，开口向上，3×10）：蓝 15（外层），黄 15（内层），位置 (0, -6)，位于圈内下方。  
  - Box C（右，开口向左，10×3）：空箱，位置 (5, -1)，开口朝向传送带并位于圈内右侧。  
- 无锁箱，轻量隐藏色，强调“先外再内、隐藏显现、分流填充”；带容量宽松避免卡死。
