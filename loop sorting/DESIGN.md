# Loop Sorting 设计文档（系统总览）

这份文档用于在上下文丢失后，快速恢复对“玩法 / 数据 / 编辑器 / 表现”的共同理解。
关卡节奏与关卡设计规范请看 `LEVELS.md`。

## 1. 核心目标
- 玩家点击箱体，把“最外层连续同色”的积木送上传送带。
- 积木沿单向传送带槽位移动，并在经过箱体开口绑定槽位时尝试入箱。
- 胜利目标：所有箱体满足“要么空，要么完成箱体（满且同色）”，并且传送带为空。

## 2. 顺序约定（必须一致，否则会出现编辑器/运行时不一致）
- 术语：外层 / 前端 / 开口侧 = 靠近开口、可被操作的那一层。
- `BoxSpec.colorCounts` 列表顺序：外 → 内（索引 0 为最外层）。
- `Container.Blocks` 列表顺序：外 → 内。
  - `TryPeek/TryPop` 读取/弹出 `Blocks[0]`。
  - `TryPush` 追加到末尾（填充最内侧空位）。

## 3. 传送带（Conveyor）
- 逻辑推进：离散 tick；表现槽位平滑移动，但游戏逻辑仍按槽位索引执行。
- Loop（表现参数）：`ConveyorPath.loop=true` 表示尾部槽位会往入口回卷；`loop=false` 则不显示“最后槽位回卷”。

### 3.1 满槽行为（规则）
- 满槽时也必须继续轮转（整体同步移动，保持相对顺序）。
- 运行时检测到满槽：临时切换到 **5x 速度**，最多跑完整一圈（`Conveyor.Length` tick）。
- 若中途变为未满：恢复正常速度；若一圈后仍满：判定失败。

## 4. 箱体出货/进货规则

### 4.1 出货（玩家点击）
- 点击箱体：自动把“最外层连续同色”作为一个 run 逐个出货到传送带，直到遇到不同颜色为止。
- 同一时刻仅允许一个箱体出货。
- 出货期间该箱体 `Busy=true`：禁止进货（不能一边出货一边进货）。

### 4.2 进货（传送带入箱）
- 仅当积木到达该箱体绑定的传送带槽位（口对口）时才检测入箱。
- 入箱条件：箱体未锁、未 busy、未满，并且（箱体为空 或 箱体最外层颜色与积木一致）。
- 新增优先级规则（空箱延后）：当积木准备进入“空箱”时，如果存在其它“非空且未满”的箱体，其最外层颜色与该积木相同，则该积木不进入空箱。
- 入箱落位：优先填充“最内侧空位”；箱内已有积木不移动。

## 5. 隐藏色（Hidden Blocks）
- 每个积木携带 `hidden` 标记。
- 连续同色 run 的隐藏状态一致：只要该 run 暴露在最外层（成为可操作层），该 run 全部解除隐藏并显示真实颜色。
- 编辑器：只需用 `H` 标注该颜色段为 hidden。

## 6. 锁箱（Locked Box）
- `BoxSpec.locked=true` 且设置 `unlockColor`。
- 锁箱在解锁前：看不到内容、不可操作、不可进货/出货、boosters 不可移动其内部积木。
- 解锁条件：任意箱体完成（满且同色）且颜色 == `unlockColor`。
- 视觉：灰色遮罩覆盖箱体，并在箱体中间标记“解锁所需颜色”。

## 7. 胜负条件与关卡流（Flow）
- 胜利：所有箱体满足“空箱”或“完成箱体（满且同色）”，并且传送带为空。
- 完成箱体：变为不可操作，并有完成覆盖效果。
- 失败：传送带满槽且快进一圈后仍满。
- `LevelFlow`：运行时按序推进；胜利进入下一关；失败弹窗“重试”。

## 8. 道具（Boosters）
- 使用道具时：暂停玩家输入；若传送带非空，以 **5x 先跑一圈**（为空则提前结束）；在“跑完一圈后的状态”上执行道具逻辑；无法入箱的积木继续留在传送带上。
- 完成颜色（Fill/Sort）：只选取“可被填满”的颜色（考虑锁箱限制），把该颜色填满一个可用箱体；不生成/删除积木；不移动锁箱/完成箱内容。
- 打乱顺序（Shuffle）：仅作用未完成且未锁箱体；按“连续色段（按行）”为整体抽取再随机塞回；保持最小连续行数约束。

## 9. 统一视觉层级（框架）
- 背景（最底）
- 传送带槽位（灰色半透明）
- 积木
- 可操作 run 黑色描边（包在积木外侧）
- 白色虚线箱体轮廓（在黑描边外侧；开口侧留空）
- 锁箱遮罩（高于积木）
- 锁箱颜色标记（高于遮罩）
- UI/HUD/弹窗（最顶）

## 10. 编辑器（LevelEditorWindow）
- 左侧关卡列表（`Assets/Levels`）快速切换；中间预览；右侧参数面板。
- 支持：拖拽 box / conveyor points；颜色段点选 + 滚轮调数量；拖拽颜色段排序（外→内）；`H` 标记 hidden、`L` 锁箱并设置 unlockColor；默认 Snap to Grid（0.5）；Play 模式下“运行时跳到当前关”。
