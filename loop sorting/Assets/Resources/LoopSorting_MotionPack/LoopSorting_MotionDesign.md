# Loop Sorting 动效设计文档（v1.0）

> 目的：在不改变规则与关卡数据的前提下，通过“信息型动效 + 反馈型动效 + 节奏型动效”，显著提升可读性、爽感与品质感。  
> 本文档为可落地版本：可直接拆给程序/特效/音效/TA，按条目实现与验收。

---

## 1. 动效设计目标（Pillars）

1) **信息更清晰**  
- 玩家一眼看懂：当前可操作箱体、可操作 run、积木将进入哪个箱体、为什么没进去（Busy/Locked/不匹配/空箱延后规则）。
2) **操作更爽**  
- 点击、出货、入箱、完成、解锁、道具使用，都要有“命中感、重量感、节奏感”。
3) **节奏更稳**  
- 传送带逻辑是离散 tick，但表现必须平滑，并且不会造成“逻辑先走、画面后跟不上”的错觉。
4) **失败更可解释**  
- 满槽进入 5x 快进的一圈，玩家应明确感知：这是“最后机会”倒计时，并理解失败原因。

## 2. 全局动效语言（Motion Language）

### 2.1 速度与节奏（建议默认值）
- 微反馈 XS：0.06–0.10s（点击压缩、轻微闪烁、outline 轻脉冲）
- 短反馈 S：0.12–0.18s（小弹性、轻转向、入槽对齐）
- 中反馈 M：0.20–0.30s（出货、入箱、完成覆盖显现）
- 大反馈 L：0.35–0.55s（解锁、胜利/失败切场、道具主表现）

### 2.2 缓动与“手感”
- 位置：`EaseOutCubic / EaseInOutCubic`（稳定、干净）
- 强调：`EaseOutBack`（小幅过冲，用于出货弹出、完成盖章）
- 失败/阻塞：`EaseOutQuad` + 回弹（明确“被挡住了”）

### 2.3 动效分层（与渲染排序一致）
建议所有动效遵循既定视觉层级（背景 → 槽位 → 积木 → 可操作描边 → 箱体虚线 → 锁箱遮罩 → 锁箱标记 → UI）。  
实现上尽量避免“UI 动效压住规则信息”或“锁箱遮罩被积木穿透”的情况。

## 3. 需要动效的系统地图（按玩法链路）

### 3.1 传送带 Conveyor
- Tick 推进的平滑位移
- Loop 回卷段（可显/不可显两种表现）
- 满槽：进入 5x 快进一圈（紧迫、警示）
- 道具前置：5x 快进一圈（与满槽区分）

### 3.2 箱体 Box
- 可点击态：呼吸/描边/轻摆（引导）
- 点击出货：开口侧“吐出”run（有节奏的连发）
- Busy：抑制反馈（半暗/锁定提示）
- 进货：开口“吸入” + 内侧落位
- 完成箱体：盖章/封存（从此不可操作）
- 锁箱：灰遮罩 + 解锁颜色标记；解锁时破封/消散

### 3.3 积木 Block
- 出货弹出（从箱体最外层到传送带槽位）
- 沿传送带移动（对齐槽位中心、轻微惯性）
- 尝试入箱成功：吸入 + 贴合落位
- 尝试入箱失败：轻碰撞回弹（原因提示）
- Hidden：被揭示时的“翻牌/揭膜”动效

### 3.4 UI/HUD/弹窗
- 关卡开始/结束切场
- Booster 选择、执行、结果反馈
- 失败重试弹窗
- 轻提示（规则解释型）：空箱延后、Busy、Locked
- FreeSlotsCounter（剩余槽位数字）的低槽/满槽警示

## 4. 关键规则的“可视化动效策略”

### 4.1 只允许一个箱体出货（并且 Busy 禁止进货）
- 出货时：当前箱体进入 **Busy 强态**（描边变硬、轻微抖动节奏停止），其他箱体进入 **可见但不可点**（轻暗 + 禁止符号短闪）。
- 如果此时有积木到达 Busy 箱体的入箱槽位：播放“碰到门口被挡住”回弹，并在箱体开口处闪一个小锁/Busy icon（0.12s）。

### 4.2 空箱延后优先级（避免玩家误解“为什么不进空箱”）
当积木到达某个空箱入箱点，但存在其它“非空且未满的同色箱体”时：
- **空箱**：播放“让路”动效（开口轻轻合一下 / outline 短熄灭）。
- **目标箱体**：闪烁同色高亮（0.2s），同时从空箱到目标箱体拉一条极细的“引导线”0.15s（信息型，不喧宾夺主）。
- **积木**：继续前进时给一个轻微“转向感/加速度”提示（0.08–0.12s）。

### 4.3 Hidden run 揭示
当 hidden run 成为最外层可操作层时：
- 该 run 的每个积木从“遮罩/问号”翻转到真实颜色（0.22s，stagger 0.03s）。
- 同时可操作描边从无到有（0.12s），形成“现在可以点”的明确提示。

### 4.4 锁箱解锁
满足解锁条件时：
- 触发解锁的“完成箱体”先播放完成盖章（见 5.6）。
- 所有 `unlockColor` 匹配的锁箱：遮罩出现裂纹/颗粒化消散（0.45s），颜色标记缩放淡出（0.18s），箱体轮廓恢复正常。

### 4.5 满槽失败（快进一圈仍满）
- 检测到满槽：进入 **Panic 模式**（5x 速度），背景/槽位加轻微速度线，屏幕角落出现小红条“满槽倒计时”（一圈内逐步缩短）。
- 一圈结束仍满：播放“停止 + 回弹”并立即切失败弹窗；失败弹窗出现前 0.15s 让传送带轻微减速到 0（不突兀）。

## 5. 动效条目表（可直接拆任务）

> 命名规范：`SYS_Action_State`（例如 `Box_Ship_RunStart`）

### 5.1 Conveyor_Tick_Move
- 触发：每个逻辑 tick（槽位索引推进）
- 表现：所有槽位平滑移动到下一个槽位位置；积木跟随槽位
- 时长：`tickDuration`（默认 0.25s）
- 曲线：InOutCubic
- 可中断：是（若进入 5x 切速，需重映射剩余路程）

### 5.2 Conveyor_Loop_Wrap
- 触发：槽位越过尾部返回入口
- loop=true：走可见回卷段（曲线路径）
- loop=false：尾端淡出（0.08s）+ 入口淡入（0.08s），位置瞬移发生在不可见区

### 5.3 Box_Interact_Hover
- 触发：指针悬停/可点击态（或移动端轻提示）
- 表现：白虚线轮廓轻脉冲（0.8s loop）、开口侧轻亮
- 注意：Busy/Locked/Completed 状态下禁止该动效

### 5.4 Box_Ship_Run
- 触发：玩家点击箱体，开始将“最外层连续同色”run 出货
- 表现：开口侧张开（或发光），run 逐个弹出到传送带入口槽位
- 时长：每个积木 0.10–0.14s，间隔 0.04–0.06s（与 run 长度相关）
- 曲线：OutBack（小过冲）
- 规则提示：开始时箱体进入 Busy 强态，结束恢复

### 5.5 Block_Enter_Box_Success
- 触发：积木到达绑定槽位且满足入箱条件
- 表现：积木沿开口吸入，落到最内侧空位；落点轻压缩（0.06s）
- 时长：0.22–0.28s
- 曲线：OutCubic + 末端轻回弹
- 音效：吸入 + 轻落位“咔哒”

### 5.6 Box_Complete_Seal
- 触发：箱体“满且同色”完成
- 表现：完成覆盖效果（可理解为盖章/封条），箱体轮廓变硬；不可再操作
- 时长：0.35–0.45s
- 曲线：OutBack（轻过冲）
- 额外：同色粒子小爆 0.15s（量小）

### 5.7 Box_Locked_Idle / Box_Locked_Unlock
- 触发：锁箱初始 / 解锁条件达成
- 初始：灰遮罩缓慢呼吸（周期 2.0s），中间显示解锁所需颜色
- 解锁：遮罩碎裂 + 淡出（0.45s），颜色标记缩放淡出（0.18s）

### 5.8 Block_Hidden_Reveal
- 触发：hidden run 暴露为最外层
- 表现：遮罩翻开/擦除 → 真实颜色
- 时长：单块 0.22s，stagger 0.03s
- 曲线：InOutCubic

### 5.9 Block_Enter_Box_Fail (Busy/Locked/Mismatch/EmptyDeferred)
- 触发：到达入箱点但条件不满足
- 表现：轻碰撞回弹（0.10–0.14s），并显示对应原因 icon（0.12s）
- 原因区分：
  - Busy：黄色小锁/忙碌符
  - Locked：灰锁
  - Mismatch：×
  - EmptyDeferred：空箱“让路”+ 目标箱体高亮（见 4.2）

### 5.10 Booster_FillSort
- 触发：使用 Fill/Sort 道具（在 5x 跑一圈后执行）
- 表现：被选中的颜色在 HUD 中聚光 → 对应箱体吸入同色光束 → 该箱体快速补齐到满
- 时长：主段 0.45–0.65s（可按补齐数量加微小 stagger）
- 注意：不生成/删除积木，仅做“重排/转移”的视觉解释

### 5.11 Booster_Shuffle
- 触发：使用 Shuffle（在 5x 跑一圈后执行）
- 表现：可作用箱体上浮 2px → 内容抖散成“色段胶囊” → 重新落回
- 时长：0.75–1.10s
- 曲线：InOutCubic（落回末端加 OutBack 轻过冲）
- 额外：短暂遮罩避免玩家看清每一步（防噪）

### 5.12 Flow_Win / Flow_Lose
- 胜利：传送带清空 + 所有箱体满足“空或完成”后触发
  - 表现：整体慢停（0.2s）→ 彩带/星星（0.8s）→ 下一关按钮入场
- 失败：满槽快进一圈仍满
  - 表现：Panic 停止 → 轻震（很克制）→ 失败弹窗

### 5.13 HUD_FreeSlotsCounter_Warn / HUD_FreeSlotsCounter_Danger
- 触发：
  - Warning：传送带空槽 `emptySlots <= 5`
  - Danger：传送带空槽 `emptySlots == 0`
- 表现：
  - Warning：数字变为琥珀色，并做轻微呼吸脉冲（scale 轻放大，不位移）
  - Danger：数字变为红色，并做更快的呼吸脉冲；进入 Danger 的瞬间额外做一次短促“被挡住”反馈（scale punch + 轻微水平抖动）
- 时长/节奏（默认）：
  - Warning pulse：周期 0.90s，最大 +6%
  - Danger pulse：周期 0.55s，最大 +10%
  - Enter Warning：0.12s scale punch
  - Enter Danger：0.18s scale punch + shake
- 实现：`Assets/Scripts/BeltCounterUI.cs`（使用 unscaled time；阈值/颜色/幅度均可在组件参数中调整）

## 6. 实现建议（程序/TA）

### 6.1 事件驱动（强烈建议）
逻辑层在关键节点抛出事件，表现层订阅并播放动效。典型事件：
- `OnBoxShipRunStart/OnBoxShipRunStep/OnBoxShipRunEnd`
- `OnConveyorTickStart/OnConveyorTickEnd`
- `OnBlockTryEnterBox/OnBlockEnterBoxSuccess/OnBlockEnterBoxFail`
- `OnHiddenReveal`
- `OnBoxCompleted`
- `OnLockedBoxUnlocked`
- `OnBoosterStart/OnBoosterExecute/OnBoosterEnd`
- `OnLevelWin/OnLevelLose`

### 6.2 速度倍乘（1x / 5x）
所有 Conveyor 与跟随它的动效统一用一个 `speedMultiplier` 控制（tickDuration / multiplier）。  
满槽与道具前置都用 5x，但 UI 提示不同，避免玩家混淆。

### 6.3 可打断与对齐
- Tick 位移动效必须保证最终位置精确落到槽位中心（误差累积会造成“漂移”）。
- 进入 5x 时，建议重新计算当前 tween 的剩余路程并重映射时长（而不是直接硬切）。

## 7. 验收清单（QA）

- [ ] 玩家能区分：Busy/Locked/Mismatch/EmptyDeferred 四类“未入箱原因”
- [ ] 传送带 tick 平滑且不漂移；5x 切换无突兀跳帧
- [ ] Hidden 揭示发生在成为最外层的同一时机，并且 run 内一致揭示
- [ ] 锁箱解锁在完成触发后联动出现，不抢镜但足够明确
- [ ] 失败过程“可预期”：玩家看到 Panic → 一圈结束仍满才失败
- [ ] 所有动效遵循渲染层级，不出现遮罩穿透/描边遮挡不一致
